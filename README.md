# Briganti Nomogram

A 32-bit Windows application for calculating the risk of LNI (Lymph Node Invasion)
based on the parameters:

BGG = Biopsy grade group 5<br>
CS  = Clinical stage at mpMRI<br>
MRI = Maximum diameter of the index lesion at mpMRI (mm)<br>
PSA = Preoperative PSA (ng/ml)<br>
PPC = Percentage of positive cores at systematic biopsy<br>


## Reference for the nomogram

Giorgio Gandaglia et al.
"Identification of the Optimal Candidates for Nodal Staging with
Extended Pelvic Lymph Node Dissection Among Prostate Cancer
Patients Who Underwent Preoperative Prostate-specific Membrane
Antigen Positron Emission Tomography. External Validation of the
Memorial Sloan Kettering Cancer Center and Briganti Nomograms
and Development of a Novel Tool"<br>
EUROPEAN UROLOGY ONCOLOGY 6 (2023) 543–552<br>
https://doi.org/10.1016/j.euo.2023.05.003<br>


## Installation

Run BrigantiNomogram-setup.exe


## Keyboard navigation
Tab:        Move to next input field<br>
Shft+Tab:   Move to previous input field<br>
F4:         Open drop down list of input field<br>
Arrow down: Select next input value<br>
Arrow up:   Select previous input value<br>
